## 🌟 About The Project

**CR7 LEGACY — THE IMMORTAL NO. 7** is an interactive football tribute dedicated to Cristiano Ronaldo, celebrating his incredible journey, achievements, mentality, and legacy with the Portuguese national team.

This project combines the atmosphere of a cinematic sports documentary with the interactive experience of a modern football game.

Explore his international career, discover memorable milestones, test your football skills, and experience the mentality behind one of football's most iconic No. 7s.

This is more than a football project.

It's a celebration of a legacy.

## ⚽ Features

### 🏟️ 1. Cinematic Landing Experience
- Immersive football-inspired introduction.
- Dramatic stadium atmosphere.
- Animated CR7 branding and iconic No. 7.
- Smooth transitions and cinematic visual effects.

### 📜 2. The Legacy Timeline
Explore important milestones from Cristiano Ronaldo's international career:

- 2003: Portugal international debut.
- 2004: UEFA European Championship.
- 2006: FIFA World Cup breakthrough.
- 2016: UEFA European Championship champion.
- 2019: UEFA Nations League champion.
- 2025: Second UEFA Nations League title.

### 🎮 3. The No. 7 Challenge
Put your football skills to the test in an interactive mini-game.

- 60-second gameplay challenge.
- Interactive football shooting mechanics.
- Power meter and scoring system.
- Combo multipliers.
- Countdown timer.
- High-score tracking.
- Victory and failure screens.

### 🧠 4. The Mentality Room

Discover five principles associated with Ronaldo's legendary mentality:

1. Discipline.
2. Consistency.
3. Sacrifice.
4. Confidence.
5. Relentless Ambition.

Includes motivational content and daily mentality challenges.

### 📊 5. The Numbers
An animated statistics section showcasing international career milestones.

| FIFA World Cup Appearances | 6 |

### 🔐 6. The Secret Experience

A hidden tribute awaits curious visitors.

### 🎨 7. Premium Visual Experience
- Dark cinematic interface.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/PeroX-Coder/CR7-Legacy.git
```

### 2. Navigate to the Project

```bash
cd CR7-Legacy
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local development URL provided by your terminal.

*Note: These commands assume the project uses a compatible Node.js-based setup. Adjust them if your generated project uses a different framework.*
